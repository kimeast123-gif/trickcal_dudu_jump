# ART V2 PILOT — Claude Code 적용·검수 지시

## 적용 대상
- 월드1 숲 compact(폭 48~140px): `forest_w1_compact_left/fill_a/fill_b/right`, `contactY=18`.
- 정령산 이프리트 lava long(길이 313~1960px): `spirit_lava_long_left/mid_a/mid_b/right`, `contactY=6`.
- **그 외 69개는 생성하지 않았다.** `GPT_ASSET_BRIEF.md` 7장에 적힌 우선 시범·승인 절차를 준수한 결과다.

## 파일 읽는 법
- `01_tiles_1x/`: 게임에 바로 넣을 수 있는 **정확한 크기의 RGBA PNG**. 원본 1:1 유지, `drawImage`에서 재축소하지 않음.
- `02_atlases_4x/`: 1x 검증 파일을 4배 정수 확대해 배치한 투명 시트. **그림의 4배 신규 정보가 들어 있는 것은 아니다.** 개별 1x 부품을 우선 사용.
- `04_specs_qa/ART_V2_PILOT_MANIFEST.json`: 각 부품의 이름, 치수, 위치, 접지행.
- `04_specs_qa/*_offline_crop_table.json`: 중간 부품을 임의 폭으로 자를 때 사용할 오프라인 시작열 후보. 브라우저 픽셀 조회 금지.
- `03_previews/`: 실제 배포본 배경과 idle 캐릭터 1프레임을 이용한 정적 합성 시안. 실제 게임 스크린샷 아님.

## 금지 사항
1. 게임 물리, 스테이지 좌표, 체크포인트, NPC 및 UI 수정 금지.
2. 스토리/월드1 숲의 다른 에셋을 현재 시제품과 무조건 혼용해 정식 배포하지 말 것.
3. 바닥/벽, 용암 점멸, 설산, 다른 69개 부품은 미승인·미생성. 유사 색상으로 임의 대체 금지.
4. `getImageData()` 등 브라우저 런타임 픽셀 읽기로 이음매를 고르지 말 것. v1.1의 file:// 실행 중단 사고 재발 방지.
5. 용암홀 천장과 낙사 개구부는 비워 두며 지붕 이미지 추가 금지.

## 설치 테스트
1. 별도 브랜치 + 기존 `?arttest=0` A/B 비교 기능 유지.
2. 실제 기존 렌더 분기(`drawThinPlatformVisual`, `drawSpiritTile`)에서 폭 분기와 전용 지역 ID를 분리.
3. 이미지의 `contactY`가 물리 `platform.y`에 맞도록 이미지 그리기 Y만 조정. 예: `drawY=platform.y-contactY` (기존 화면-월드 좌표 변환을 고려).
4. 정규 반복 모듈 경계는 RGBA 채널이 일치하게 제작했지만, **임의 길이 절단은 화면·충돌 검수를 거쳐 승인**할 것.
5. 숲 48/64/92/110/140, 용암 313/480/851/1371/1960 폭, 실제 게임에서 모든 사용 폭을 테스트.
6. `file://`, `http://`, 모바일 가로 화면을 각각 테스트. 회귀 오류가 나면 새 에셋만 끄고 배포본으로 되돌릴 수 있게 유지.
7. `art_physics_identity.py` 100% 동일, 접지 ±2px, 파츠 혼용 0을 통과해야만 다음 단계 제작 승인 요청.

## QA 결과와 제한
- 전 부품 RGBA 및 픽셀 규격 검사 통과, 접지선 위 알파 불투명 픽셀 없음.
- 정규 모듈 연결부: 첫/마지막 1x 경계 열 RGBA 차이 0 (개별 파일 기준).
- 임의 폭 오프라인 절단 테이블은 후보값이며, **실제 렌더러 전체 구간 통과 증명이 아니다.**
- 실제 게임을 실행하거나 커밋하지 않았음. 사용자 아트 승인 전 공개 배포 금지.
