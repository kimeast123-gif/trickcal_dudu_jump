# ART V2 — Batch 1 Forest Rev2 (14 assets) / Claude 적용·재검수

대상: `GPT_BATCH1_FOREST_REVISION_BRIEF.md`의 월드1 숲 지면·벽·받침 14종. 용암 7종과 rev1 승인 8종, 후보 A는 변경하지 않는다.

## 정확한 적용 범위

`01_tiles_1x/forest_w1_*.png` **14개만** 기존 Batch1 동명의 파일에 덮어쓴다. 파일명·폭·높이·접지 위치는 `04_specs_qa/ART_V2_FOREST_REV2_MANIFEST.json`을 따른다. 4배 아틀라스는 시각 검토용이며 런타임은 1배 PNG를 사용한다.

## 검수 선행 확인

1. 이미지 색·질감의 중심은 `forest_standard_candidate_A.png`와 rev1 compact 이미지이며, 이번 변경은 지면 윗단의 흙색 연결·몸통·벽·절벽 끝단·받침의 조형 개선이다.
2. 윗단 3종과 몸통 2종, 받침, 벽 몸통/엣지는 자체 반복 경계의 픽셀 차이 0으로 확인했다. 단 **완전한 무늬 비반복**은 픽셀 검수로 보장되지 않는다. 넓은 지면(860px)과 벽(높이 1,145px)을 실제 화면에서 먼저 관찰한다.
3. 자동 추정 접지행은 `ground_top_a/b/c=25`, `ground_cliff_left/right=25`, `wall_top=6`을 유지하며 게임 물리 좌표를 수정해서는 안 된다.
4. 새 절단 위치표 `04_specs_qa/{ground_top,ground_body,under_support}_offline_crop_table.json`은 새 이미지로 재계산한 오프라인 조립 참고값이다. **브라우저 런타임에서 `getImageData()`로 절단점을 구하지 말 것.**
5. 이 ZIP은 이미지 작업본이고, `?artv2=0` 기존 버전 대비, 파일 직접 열기(`file://`)와 HTTP 환경, 실제 게임 충돌/접지 검수는 Claude가 해야 한다.

## 시각 검수에서 꼭 판정할 것

- 월드1 숲 1-1~1-4: 기존 `132/132` 적용 범위를 유지하는가? (코드 통합 과정에서 옛 에셋이 한 화면에 섞이지 않는가?)
- 폭 320, 520, 860px 지면에서 윗단과 몸통 사이 색띠가 발생하는가?
- 지면 몸통에서 **큰 바위·잔돌의 같은 무늬가 151px마다 도장처럼 보이는가?** 그렇다면 이미지 접합 문제와 구분하고, 새 그림의 대비 또는 렌더 타일 선택 순서를 추가로 조정할 것. 승인 판정은 보류한다.
- 외곽 절벽 파츠의 바깥쪽은 둥글게 재제작했지만, **지면 몸통을 에셋 끝까지 직사각형으로 깔아 두면 투명 실루엣 뒤에서 구형 사각 끝이 그대로 보일 수 있다.** 이때 이미지 자체를 다시 일그러뜨리지 말고, 기존 충돌·좌표를 보존하면서 바닥 몸통의 양 끝 렌더링 영역을 클리핑해 가장자리 마감이 실제 화면에 드러나게 한다.
- `wall_body`를 폭 52~76px로 가운데 크롭하고, 160~1,145px로 반복할 때 뚜렷한 세로선·복제감이 있는가?
- `under_support` 520px, 1,320px의 받침에서 상단 긴 발판과 재질이 이어지는가? 새 받침 윗면에 잔디처럼 보이는 가짜 접지선이 없는가?
- 기존 NPC·체크포인트·수집물·UI·점멸·이동 발판·물리·레벨 데이터는 변경하지 않는다.
