## 3. 수정 내용

### 3.1 흙 질감 (몸통, 벽, 받침 공통)

1. **덩어리진 흙 + 작은 돌.** 크고 작은 흙덩이가 맞물린 모양을 3~4단계 명암으로 그린다(덩어리 위쪽은 조금 밝게, 아래쪽은 어둡게, 왼쪽 위 빛). 작은 돌(밝은 회갈색, 지름 4~10px)과 가는 뿌리 조각을 드문드문 섞는다. 후보 A와 배포본 지면이 기준.
2. **색과 밝기:** 후보 A와 rev1 작은 발판의 흙색 범위(대략 RGB 110~125, 85~95, 45~50 중심)에 맞춘다. 지난번보다 한 단계 밝고 따뜻하게. 어두운 부분은 그늘에만.
3. **방향성 무늬 금지:** 세로 홈, 가로 줄, 규칙적인 벽돌 모양처럼 한 방향으로 이어지는 무늬를 넣지 않는다. 흙덩이 크기와 위치를 불규칙하게 흩어서, 타일이 이어져도 격자가 보이지 않게 한다.
4. **단독 표시 금지(지난 시범에서 받은 주의):** 한 번만 보여야 할 큰 돌, 꽃, 버섯, 점 하나를 반복 타일에 넣지 않는다. 작은 돌은 여러 개를 고르게 흩어 어느 하나도 눈에 튀지 않게.
5. **선명도:** 가장자리와 덩어리 윤곽은 후보 A만큼 선명하게. 확대한 듯 흐릿한 느낌 금지.

## 4. 바꾸면 안 되는 것

- 위 표의 크기, 접지선, 파일 이름.
- 투명 RGBA PNG. 1배 정확 크기(`01_tiles_1x/`) + 4배 시트(`02_atlases_4x/`).
- 반복 경계 RGBA 차이 0 목표. 가로 반복 부품(윗단, 몸통, 받침)은 **임의 폭 절단 표를 새 그림으로 다시 계산**해서 보낸다.
- 벽 몸통, 벽 테두리, 받침, 지면 몸통에 잔디·윗면을 그리지 않는다(밟는 면처럼 보이면 안 된다).
- 용암 7개, rev1 승인 8개, 후보 A는 다시 만들지 않는다.
