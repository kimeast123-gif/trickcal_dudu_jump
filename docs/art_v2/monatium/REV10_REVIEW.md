## 3. 화면 판정

비교: `rev10/r10_s1.jpg`, `rev10/r10_s2.jpg`. 각 줄은 왼쪽부터 원래 배포본, V2, 수정본이다.

- **탑 내부:** 어두운 유리창과 굵은 철골 틀이 되었다. 낙서선과 막대 모양 건물이 없어졌고, 앞의 발판과 두두가 확실히 떠 보인다.
- **탑 벽:** 막힌 철판이 되어 벽으로 읽힌다.
- **야간:** 철골이 중간 회색이 되어 V2처럼 밤하늘 위에서 튀지 않는다. 윤곽은 보인다.
- **바깥 발판:** 밝은 윗선과 어두운 몸통이라 광장과 하늘 위에서 더 잘 보인다.
- **V2 검수의 정정:** 모나티엄 A 중간의 "비쳐 보이는 건물 덩어리"(A2, A3)는 벽이 아니다. 하늘길 발판 `M-SKY-SAFE2` 아래의 받침 기둥(`rooftop_pier`)이고 충돌이 없다. 승인된 V2 기둥 그림 그대로이며, 격자 받침으로 보이는 것은 문제가 아니다.

**관찰 (불합격 아님)**
- 탑 내부가 큰 어두운 유리 칸 위주라 세부가 적다. 밝은 낮 배경 옆에서는 다시 큰 어두운 덩어리로 보인다.
- 그래도 원래 배포본의 남색 격자보다 덜 차갑고, 발판 판독이 우선이라 통과로 둔다.
- 더 다듬는다면 유리 안쪽에 아주 흐린 실내 조명이나 반사를 더하는 정도이다(밝기는 38 이하 유지).
