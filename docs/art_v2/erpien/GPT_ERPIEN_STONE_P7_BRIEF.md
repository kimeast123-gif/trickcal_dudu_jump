이번 지시는 이 네 원인을 각각 막는다.
- 2장 작업 절차: 리샘플, 자르기, 코드 그리기를 금지한다.
- 3장 반복 타일 그리는 법: 이음매를 그림으로 잇는다.
- 5장 자가 검사: 실패를 잡는 같은 기준으로 납품 전에 거른다.

## 2. 작업 절차 (반드시 이 순서)

1. **2배 원판을 정확한 크기로 만든다.** 각 부품의 "2배 원판 크기"(4장 표)로 빈 캔버스를 만든다.
   - 생성기가 다른 크기를 내놓으면 **가로세로 비율이 같도록 잘라 내고(crop)** 원판 크기로 맞춘다.
   - 가로와 세로를 다른 배율로 늘리거나 줄이는 것은 **금지**한다(아치가 늘어나는 원인).
2. **원본을 안내선으로 깐다.** 원본 부품을 정확히 2배(최근접 확대)로 키워 아래 층에 깐다. 다음을 그대로 따른다.
   - 윗면 줄(원본 윗면 중앙값 × 2)
   - 아치·처마·모서리 위치
   - 바깥 윤곽
   - 안내선 층은 납품 전에 지운다. 원본 픽셀을 결과에 섞지 않는다.
3. **원판에 손그림으로 칠한다.** 생성 이미지를 쓰더라도 결과는 원판 위에서 다시 칠해 정리한다.
   - 쓰지 않을 것: 도형 함수(사각형, 다각형), 노이즈 생성 질감, 원본 위 덧칠
4. **반복 부품은 3장 방법으로 이음을 그린다.**
5. **한 번에 정확히 50%로 줄인다.** 2배 원판을 LANCZOS로 가로세로 똑같이 50% 줄여 납품 크기를 만든다.
   - 줄인 뒤 다시 늘리거나 손대지 않는다.
   - 원판 PNG도 함께 납품한다. 자가 검사가 원판 → 납품 파일 일치를 확인한다.
6. **색을 원본에 맞춘다.** 부품마다 불투명 픽셀 평균색이 원본과 채널별 14 이내여야 한다. P6은 석조가 주황 쪽(`#c9aa92` 대 원본 `#bca8a4`)으로 기울었다.
7. **자가 검사를 돌린다**(5장). 모두 PASS일 때만 납품한다.

## 3. 반복 부품 그리는 법

**긴 발판 (`stone_left`, `middle_a/b/c`, `right`, `inner_strip`)**
- 가운데 세 장과 `inner_strip`은 **같은 높이의 띠 구조**(윗면, 아치띠, 아래 몰딩)를 같은 줄에 갖는다. 띠의 위아래 경계 줄이 네 장 모두 같아야 한다.
- 이음 맞추기:
  - 가운데 한 장을 먼저 그린다.
  - 나머지 가운데 두 장과 `inner_strip`은 그 장의 **왼쪽·오른쪽 끝 열 16px(원판 32px)을 그대로 복제한 뒤** 안쪽만 다르게 칠한다.
  - 양 끝 부품(`left`의 오른쪽 끝, `right`의 왼쪽 끝)도 같은 끝 열에서 시작한다.
  - 그러면 어느 순서로 붙여도 이음이 그림으로 이어진다. 끝 픽셀만 억지로 같게 덮어쓰면 1px 안에서 그림이 끊겨 보인다.
- 아치는 원본과 **같은 개수, 같은 위치**로 둔다. 반복 단위(가운데 260px) 안에 아치가 정수 개 들어가야 한다.
- `inner_strip`은 게임이 아무 데나 잘라 끼우는 중립 조각이다. 아치를 넣지 말고 원본처럼 장식 없는 띠로만 둔다. 아래 윤곽은 폭 전체에서 같은 줄(±2)이다.

**땅 몸통 (`stone_ground_body_a/b`, 상하좌우 반복, 세로 벽·가로 보로도 쓰임)**
- 2배 원판에서 **반 칸 밀기(offset) 방법**을 쓴다.
  1. 다 그린 원판을 가로·세로로 절반씩 순환 이동한다(가장자리가 가운데 십자로 모인다).
  2. 가운데 십자 이음을 손으로 다시 칠해 잇는다.
  3. 원래 위치로 되돌린다.
- 돌 블록 줄 높이와 엇갈림 주기는 타일 크기를 나누어떨어지게 한다(예: 높이 240에 줄 높이 40 × 6줄, 블록 길이 65 또는 130).
- 같은 자리에 반복되는 특징 블록(금 간 돌, 얼룩)은 두지 않는다.
- 3×3 미리보기에서 반복이 읽히면 안 된다. 자가 검사가 `*_3x3_preview.jpg`를 만든다. 납품 전에 직접 본다.

**땅 윗단 (`stone_ground_top`, `_a/_b/_c`) ↔ 몸통**
- 게임은 몸통을 윗단의 **118줄**부터 그린다. 윗단 118~125줄의 색과 결이 몸통 0~7줄과 같아야 한다.

**절벽 (`stone_ground_cliff_left/right`)**
- 몸통 쪽 30px은 몸통과 같은 돌 블록과 같은 색이다. 이끼나 다른 재질로 경계를 덮지 않는다.
- P6은 이끼 낀 흐린 모서리 때문에 경계가 지저분했다.

## 5. 자가 검사 (납품 전 필수)

```
pip install numpy pillow
python erpien_self_check.py <원본 폴더> <납품 webp 폴더> <2배 원판 png 폴더>
```

부품마다 다음을 확인한다. 원본 31개를 원본에 대고 돌리면 235/235 PASS가 나오도록 맞춘 기준이다.
- 크기
- 선명도: 원본의 95% 이상
- 큰 명암: 원본의 90% 이상
- 평평한 면: 원본 + 5%p 이하
- 평균색: 원본과 채널별 14 이내
- 윗면 줄: 원본 윗면 ±2
- 밟는 선 위: 원본보다 많이 채우지 않음
- `inner_strip` 아래 윤곽: 평평
- 2배 원판: 50% 축소와 일치
- 이음매·타일 반복·윗단↔몸통·절벽↔몸통: 원본보다 나쁘지 않음

참고로 지난 시안을 같은 스크립트로 돌리면 P5는 145/235, P6은 159/235였다. **모든 줄 PASS**가 납품 조건이다.
