# 에르피엔 도시 석조·성 내부 다시 그리기 지시 (GPT용): 31개

> 이 문서를 그대로 GPT(이미지 생성)에게 전달한다. 5장의 이미지를 함께 첨부한다.
> 크기, 파일 이름, 밟는 선은 `GPT_ERPIEN_P5_BRIEF.md` 2부·3부 표와 같다. 이 문서만으로 작업할 수 있게 표를 다시 적었다.
> 숲 관문 16개는 승인 후보이므로 이번에는 만들지 않는다.

---

## 1. P5가 반려된 이유

P5 석조·성 내부는 숫자 규격(크기, 밟는 선, 이음매 0, 선명도, 몸통 시작 줄)을 모두 맞췄다. 하지만 게임 화면에서 원본보다 나빠 보여 반려했다(`p5/stone_home_rejected_sheet_A.jpg`, `_B.jpg`).

1. **코드로 그린 그림이다.**
   - 동봉 `build_p5.py`를 보면, 사각형·둥근 사각형·다각형·노이즈 질감을 프로그램으로 그리고 생성 이미지 일부를 합성했다.
   - 그래서 면이 평평하고 윤곽선만 있는 도식처럼 보인다.
2. **원본의 정체성이 사라졌다.**
   - 석조: 긴 발판 측면의 돌 아치 장식띠, 벽 위 처마 몰딩이 없어지고 평평한 판이 되었다. 짧은 발판은 상자처럼 보인다.
   - 성 내부: 햇빛 줄무늬, 깊이감 있는 아치 패널 명암, 금색 몰딩의 입체감이 없어져 연한 선 그림이 되었다.
3. **반복이 어긋난다.** 성 내부 땅(최대 4200px)에서 세로 줄과 아치 선이 반복 단위마다 끊기고 어긋난다.
4. **명암이 얕다.**

   | 부품 | 큰 명암 폭(원본 → P5) | 평평한 면 비율(원본 → P5) |
   | --- | --- | --- |
   | `stone_middle_a` | 13.9 → 10.3 | 9% → 13% |
   | `stone_single_small` | 16.9 → 9.3 | 6% → 12% |
   | `stone_ground_body_a` | 7.1 → 4.4 | 15% → 21% |
   | `home_middle_a` | 12.9 → 8.0 | 14% → 21% |
   | `home_single_small` | 16.6 → 8.1 | 12% → 18% |
   | `home_ground_body_a` | 6.2 → 2.7 | **31% → 69%** |

   - 큰 명암 폭: 16px 덩어리 평균 밝기의 표준편차(0~100 기준)
   - 평평한 면 비율: 밝기 변화가 거의 없는 픽셀의 비율
5. 오른쪽 절벽의 몸통 쪽 색이 몸통과 다르다(석조 6.3, 성 내부 8.8, 기준 3).

## 2. 이번 방식

- **손으로 그린 일러스트로 처음부터 칠한다.** 도형 그리기, 노이즈 질감, 프로그램 생성 무늬로 만들지 않는다. 원본 위에 덧칠하거나 색만 바꾸지도 않는다.
- **원본을 구도 참고로 쓴다.**
  - 원본 부품에 있는 요소를 **같은 자리에** 다시 그린다.
    - 석조: 아치 장식띠, 다듬은 돌 모서리, 처마 몰딩
    - 성 내부: 아치 패널, 금색 띠, 기둥 홈
  - 원본은 이미 공식 배경과 잘 어울린다. 목표는 같은 구성을 더 선명하고 풍부한 회화풍으로 다시 그리는 것이다.
- 원본 캔버스보다 크게 그려 줄여도 된다(작게 그려 키우지 않는다).

## 3. 공통 규칙

1. 왼쪽 위에서 햇빛이 든다. 돌과 대리석마다 밝은 면, 중간 면, 그늘 면, 깊은 홈의 4단계 명암을 둔다. 돌출부 아래에는 짧은 그림자를 넣는다.
2. 밟는 선 위는 투명이다(장식은 가로 30% 이하, 최대 8줄).
3. 반복 부품의 좌우(몸통은 상하좌우도) 끝 픽셀이 이어진다(차이 0).
4. **반복 단위 정렬:** 아치, 기둥, 돌 블록 같은 규칙적인 무늬는 반복 단위 폭(가운데 260px, 성 내부 몸통 300px, 석조 몸통 260px) 안에 **정수 개**가 들어가게 배치한다. 무늬가 타일 끝에서 끊기지 않게 한다.
5. `stone_inner_strip`의 아래 윤곽은 폭 전체에서 같은 줄(±2줄)이고, 가운데 부품 좌우 끝 아래 윤곽과 같은 높이다.
6. 윗단의 "몸통 시작 줄"(석조 118, 성 내부 560) 아래 부분과 몸통 첫 줄은 색, 밝기, 결이 같다(차이 3 이하). 경계에 가로 줄눈이나 그림자 띠를 두지 않는다.
7. 절벽 좌우의 몸통 쪽 30px은 몸통과 같은 재료와 색이다(차이 3 이하, **왼쪽·오른쪽 모두**).
8. 석조 땅 몸통 타일은 세로 벽과 가로 보(폭 64~1206px)로도 반복된다. 세워도 자연스러운 블록 쌓임이어야 한다.
