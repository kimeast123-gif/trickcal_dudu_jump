## 3. 게임 적용

- **용암 웅덩이 (지적 2):**
  - `terrain-art.js`의 새 `lp` 부품(양 끝 32 + 가운데 64 반복)으로 그린다. 양 끝 돌턱은 위험 범위 밖으로 16px씩 걸친다.
  - 예전 그림(검은 테두리, 주황 막대, 밝은 외곽선)은 새 부품을 못 불러올 때만 그린다(`spirit-mountain.js`가 `drawLavaPoolArt`를 먼저 부른다).
  - 열기 번짐, 불꽃, 기포, 불티는 그대로 움직인다.
  - 이제 판 위에 얹힌 막대가 아니라 **판이 파인 홈에 용암이 고인 모습**이다(`rev1_pool_zoom_forest_walls.jpg` 맨 위 확대).
- **벽 끝 마감 (지적 3의 남은 부분):** 아래가 아무 데도 닿지 않는 벽에만 붙인다.

| 지역 | 마감을 붙인 벽 | 판단 기준 |
| --- | --- | --- |
| 정령산 | 문 위 벽 MW2(동굴), MW4(용암), 기둥 B1(동굴), B6(용암) | 바로 아래나 옆에 발판·벽 그림이 없다 |
| 스토리 숲 | F-CLIFF-02, F-DROP-BARRIER(매달린 벽) | 벽 폭의 40% 이상 겹치는 발판·땅이 벽 아래 30px 안에 없다 |
| 월드1 숲 | W1-S1-WALL-TALL, W1-S2-WALL-LOW-L | 같은 기준 |

- 벽보다 마감 부품이 좁으면(MW2는 161px) 마감 부품을 옆으로 이어 붙인다. 좌우 이음매 차이가 0이라 이음매는 보이지 않는다.
- **조건부:** 아래 윤곽이 완만한 곡선(깊이 차이 10px)이라 "깨진 바위 덩어리"라기보다 둥글게 다듬은 끝으로 보인다. 잘린 단면처럼 보이던 문제는 없어졌다. 더 거친 끝을 원하면 이 5개만 다시 요청한다.
