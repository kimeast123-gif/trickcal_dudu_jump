## 3. 공통 규칙 (모든 부품)

1. **화풍:** rev1 승인 부품과 같은 회화풍. 부드러운 같은 계열 외곽선(1~2px 상당), 3~4단계 덩어리 명암, 왼쪽 위 빛. 사진풍, 픽셀아트, 3D 렌더, 굵은 검은 선 금지.
2. **윗면은 수평, 접지선 한 줄이 분명하게.** 원근으로 내려다본 넓은 윗면 띠를 그리지 않는다. 접지선 위에는 짧은 잔디 끝·눈 끝만(최대 6px, 가로 30% 이하. 숲 긴 발판만 후보 A처럼 잔디가 21px까지 올라옴).
3. **두께는 표의 높이 안에서.** 아래로 늘어진 뿌리, 고드름, 종유석, 공중섬처럼 뾰족한 바닥 금지.
4. **반복 조각(mid, fill, body, tile):** 눈에 띄는 단독 무늬(꽃, 수정, 소용돌이, 얼굴, 점 하나) 금지. 잔잔한 결만. 양끝 세로줄은 서로, 그리고 끝 조각 안쪽과 색·밝기·윗면 높이·아래 윤곽이 맞아야 한다(목표 RGBA 차이 0).
5. **끝 조각:** 안쪽은 반복 조각과 이어지고 바깥쪽은 둥글게 또는 살짝 깎인 바위 모서리로 마감.
6. **배경 없음, 그림자·빛 번짐이 부품 밖으로 나가지 않게.** 글자, 서명, 워터마크 금지.
7. **한 패밀리 안은 한 세트로**(같은 재질·색·두께감), **패밀리끼리는 재질이 실제로 다르게**(색 필터만 바꾼 것처럼 보이면 안 됨).
8. **밟는 면이 아닌 것은 발판처럼 보이지 않게.** 벽 몸통, 하부 받침, 바닥 아래 몸통에는 잔디·눈 윗면을 그리지 않는다(윗면 캡 부품만 예외).

## 7. 제출 전 확인 (묶음마다)

- [ ] rev1 승인 부품과 나란히 놓았을 때 같은 손으로 그린 화풍인가
- [ ] 크기, 접지선, 파일 이름이 표와 같은가. 투명 RGBA인가
- [ ] 접지선 위에는 짧은 장식만 있는가(숲 긴 발판만 21px 예외)
- [ ] 반복 조각을 자기 자신, 다른 변형, 끝 조각과 이어 붙였을 때 경계가 안 보이는가(RGBA 차이 측정값 첨부)
- [ ] 반복 조각에 꽃·수정·소용돌이·점 하나 같은 단독 표시가 없는가
- [ ] 가장자리가 후보 A만큼 선명한가(흐릿한 확대 느낌 없음)
- [ ] 붉은 기운이 rev1 용암판 이하인가, 빛나는 균열이 없는가
- [ ] 점멸판이 단단한 발판과 한눈에 구분되는가
- [ ] 벽 몸통·받침·바닥 몸통에 잔디나 눈 윗면이 없는가
- [ ] 같은 패밀리는 한 세트, 패밀리끼리는 재질이 다른가
- [ ] 절단 표, 매니페스트, 해시, 띠 그림, 합성 시안을 함께 넣었는가
