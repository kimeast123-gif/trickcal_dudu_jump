# 월드4 4-2 「낡은 저택」 배치표 (1차, 사용자 검수 전)

손그림 `ghost_swamp_map_2.png`(1209×482)을 옮긴 표. 데이터는 `ghost-swamp.js`의 `GS42_LEFT`, `GS42_LIFT`, `GS42_RIGHT`, `GS42_WALLS`.

- 맵 폭 5,900px. 지시서 권고는 8,000~10,000px인데, 기둥 오른쪽 구간은 손그림에서 발판이 촘촘해 x를 손그림의 5배로만 펼쳤다. 더 펼치면 이웃 발판 사이가 한 번 점프 거리를 넘는다. 직접 뛰어 보고 판단해 주세요.
- y는 손그림의 3배(손그림 맨 아래 = 게임 y 580).
- 기둥 왼쪽 발판은 앤티크 나무(bg2), 오른쪽은 썩은 나무(bg3)다. 배경은 기둥이 화면 가운데를 지날 때 260px 구간에 걸쳐 bg2→bg3로 서서히 바뀐다.

## 흐름

1. **시작(왼쪽 아래):** 오른쪽으로 계단 A1~A3를 오른다.
2. **리프트(x 340 검은 세로선):** y 300~-110을 6초에 한 번 왕복한다.
3. **왼쪽 위로 되돌아 오르기:** B1→B2→B3를 밟는다.
4. **기둥 넘기(v1.9 수정):** 손그림의 위쪽 긴 가로선은 길쭉한 발판이 아니라 **좌우로 오가는 발판**(TOPRIDE, 폭 200)의 길이다. 발판은 x 407~2386을 13초에 한 번 왕복하며(가운데 최고 430px/s, 왼쪽 정지 위치를 반 발판만큼 오른쪽으로 옮겨 기다림을 줄임), B3 위를 지날 때 올라타 큰 기둥 위를 건너간다. 기둥 꼭대기는 그 길 바로 아래에 있어 아래로는 지나갈 수 없다.
5. **체크포인트:** 윗길 끝 오른쪽의 CP.
6. **썩은 방(발판 밭):** 일반 12개, 점멸 19개. 빨간 원 발판은 R3, R9, R11, R18, R20, R28, R29이고, 아래쪽 가로선의 좌우 발판(LOWRIDE)도 빨간 원 발판이다.
   - **아래쪽 가로선(v1.9 수정):** 좌우로 오가는 발판(LOWRIDE, 폭 250)이 x 4375~5425를 9초에 한 번 왕복한다. 오른쪽 끝 너머 END 발판 위에 **황금 크레파스**(노란 별)가 있다.
   - 점멸: 켜짐 2.1~2.5초, 경고 0.6초, 꺼짐 0.85초, 위상은 발판마다 다르다.
   - 갈색 막대와 벽:
     - BAR: R12 바로 위 판자(R12에서 위로 바로 뛰지 못함).
     - HANG1: 천장에서 R22 위 90px까지 내려온 벽(걸어서는 지나가고 점프로는 막힘).
     - HANG2: 천장에서 R30 오른쪽까지 내려온 벽(골은 아래로 돌아가야 함).
     - GOALPOST: 골 발판 왼쪽 아래 기둥.
7. **골(오른쪽 위 깃발 발판):** 밟으면 납치 장면이 시작된다.

## 림의 착지 공격

- 빨간 원 발판에 **다른 발판에서 와서** 착지하면, 림이 발판 반대쪽 끝 옆에 나타난다.
  - 0.6초 동안 발판 윗면이 붉게 빛난다(예고).
  - 그다음 붉은 낫 베기가 발판 위를 760px/s로 지나간다.
  - 발판 윗면에서 46px보다 높이 떠 있으면 맞지 않는다. 예고 중에 점프하면 피한다.
- 공격 모션은 `Attack1_1`과 `Attack2_1` 중 하나를 매번 무작위로 고른다.
  - 모션의 실제 휘두르는 프레임을 베기가 나가는 순간에 맞췄다: Attack1은 400ms(6번째 프레임), Attack2는 930ms(14번째 프레임).
- 같은 발판에서 제자리 점프 후 다시 착지해도 다시 발동하지 않는다. 다른 발판을 밟고 돌아오면 다시 발동한다. 체크포인트에서 다시 시작하면 처음 착지부터 다시 발동한다.
- 맞으면 기존 피격 규칙을 따른다(체력 -1, 넉백, 무적 시간).
- QA용 고정: 주소에 `?gsattack=1` 또는 `?gsattack=2`를 붙이거나, `window.__gsForceAttack = 1|2`.
- 확인: 두 모션 모두 가만히 서 있으면 체력 5→4.
