## 3. 기믹 동작

- **시작**: 출발 깃발에서 시작하면 시저(앞)와 리온(뒤)이 바로 오른쪽으로 달립니다. 속도 345px/s(마요 최고 추격 속도 314의 1.10배). 옥상 다섯 칸을 실제 점프 궤적으로 건너고, 마지막 옥상에서 화면 위로 크게 뛰어 나갑니다. 두두와 부딪히지 않습니다. 두두는 정확히 2.0초(게임 시간) 동안 움직이지 않습니다. 중간 체크포인트에서 다시 시작하면 러너와 대기는 없습니다.
- **드론**: 화면 아래에서 대기 → 두두가 정지 지점에서 520px(플랫폼 두 개쯤) 안으로 오면 1.3초 동안 솟아올라 정지 → 조준선(짧은 점선)을 보인 뒤 마요의 바람총 탄을 두두 쪽으로 쏩니다(600px/s, 유도 없음, 약 1.66초 간격. v1.5.1에서 둘 다 1.5배로 강화, 이전 400px/s·2.49초). 두두가 피격 무적일 때는 쏘지 않습니다. 본체에 닿으면 피격. 위에서 밟으면 쓰러지며(Die 모션) 두두는 튀어 오릅니다. 1,500px 넘게 멀어지면 멈춥니다. 재시도하면 8대가 대기 상태로 다시 놓이고 중복 생성되지 않습니다.
- **전기장**: 보이는 가운데 줄(폭 14px)과 판정이 같습니다. 두두 몸통 판정(폭 32px)과 겹치면 기존 피격(체력 −1, 무적 2.15초, 넉백)입니다. 바깥쪽 붉은 빛(폭 32px)은 장식이라 닿아도 괜찮습니다.
- **이동 발판**: 기존 `motion` 발판이라 탑승, 동승, 체크포인트 복귀 시 위치 초기화가 그대로 동작합니다. M2는 오른쪽 끝이 전기장까지 가므로 발판 왼쪽에 서 있어야 합니다. 방향 화살표나 시간 표시는 없습니다.
- **진압반**: 기존 `guard1`/`guard2` 순찰(대기 → 경고 → 돌진 → 휴식 → 복귀)입니다. 타원마다 1명이고, 종류(1·2), 출발 위치(타원 끝에서 0–60px), 첫 출발 지연(0–0.7초)만 판마다 무작위입니다. 순찰은 검은 선 범위 밖으로 나가지 않습니다. 점프로 넘을 수 있습니다.
- **갈색 셔터 (v1.5.2)**: 셔터 밑은 낙사 구덩이이고, 셔터(폭 76px)가 두 발판 사이 틈 전체를 덮습니다. 걸으면 발판 끝에서 셔터에 막혀 떨어질 일이 없고, 셔터 앞에서 대시하면 밑으로 빠져나가 바로 다음 발판에 닿습니다. 드론 탄은 셔터를 뚫습니다.
- **갈색 셔터 (공통)**: 지시서의 "대시 통과 높이"를 그대로 구현했습니다. 두두는 서 있을 때 키 60px, 대시 중에는 32px로 판정하고, 셔터 아래 끝은 통로 위 44px입니다. 걸으면 셔터에 막히고, 셔터는 2단 점프로도 넘지 못할 만큼 높으며 위에 설 수 없습니다. 대시만 밑으로 빠져나갑니다. 대시가 셔터 밑에서 끝나면 빠져나올 때까지 대시가 이어집니다. W2와 W5 뒤 발판은 80px 높아 **대시 후 점프**, W3 뒤는 205px 낮아 대시 후 내려갑니다.
- **NPC**: 165px 안으로 다가가면 지정 모션과 대사, 멀어지면 대기 모션입니다. 가장 가까운 한 명의 말풍선만 보입니다. 리온은 `Lion_Mask_Happy_1`/`Lion_Idle`, 시저는 `Scizor_Sad_4`/`Scizor_Idle`, 엘레나·아멜리아·칸나는 기존 대기 모션(이들은 대기 모션만 있음)입니다. 광장 오른쪽 끝(16,330)에 닿으면 클리어 창이 뜹니다.

## 4. 배경과 음악

- 배경 음악은 사용자가 준 `24. Monatium.mp3`(`assets/event/monatium.mp3`, 트랙 5)입니다. 끝의 무음 1.5초를 빼고 0.05~94.45초를 반복합니다. 월드1과 스토리 음악은 그대로입니다.

- 원경은 받은 그림 그대로입니다. 출발~타워 앞은 `밤의 모나티엄 3`(가로수, 고가 모노레일), 타워~고가는 `밤의 모나티엄 1`(차가운 빌딩), 셔터 구간~계단은 `밤의 모나티엄 3`을 좌우 반전, 광장은 `밤의 모나티엄 2`(시청)입니다. 구간 경계는 1,000px에 걸쳐 섞이고, 각 그림은 1.15배로 키워 구간을 지나는 동안 천천히 흐르고 위아래 카메라에 따라 움직입니다.
- **시청 그림은 카메라 중심이 23,350을 넘을 때부터만** 그립니다(23,350–23,650에서 서서히 나타남, v1.5.2까지는 15,150). 이때 두두는 광장 바닥(23,200~)에 있습니다. 패럴랙스로 미리 보이는 경로는 없습니다(`night_checks.py backdrop`).
- 스케치의 빌딩 기둥은 창문 불빛이 있는 야간 빌딩으로, 가는 발판은 하늘색 테두리 강철 발판으로, T자는 기둥 달린 고가로, 갈색 상자는 갈색 셔터로 그렸습니다. 타워는 바깥 벽과 실내 벽판, 출입구와 바닥 틈의 노란 테두리로 그렸습니다.
- 성능: 빌딩 외벽, 광장 바닥, 타워 실내, 축소한 배경 그림은 처음 한 번 따로 그려 두고 다시 씁니다(v1.4.2 모나티엄 B와 같은 방식). 카메라에서 4,200px 넘게 떨어진 것은 메모리에서 지우고, 좌우 반전 구간은 같은 그림을 뒤집어 복사합니다. 야경 맵을 나가면 미리 그려 둔 그림(약 20MB)을 모두 놓습니다(v1.5.4).

## 5. 판단해서 정한 것 (사용자 확인 필요하면 바꿀 수 있음)

1. **갈색 셔터 밑 통로**: 스케치에서는 셔터가 발판 사이 틈 위에 있지만, 틈 위에 걸면 "걸어서 떨어지며 셔터 밑을 지난 뒤 공중 점프로 복귀"하는 우회가 항상 생겼습니다(`night_hops.py`로 확인). 그래서 셔터 밑에는 짧은 철망 통로를 두고, 대시 중 키가 낮아지는 방식으로 대시만 통과되게 했습니다.
2. **드론 밟기**: 드론 파괴 모션(Die)이 있어 위에서 밟으면 쓰러지게 했습니다. 몸통 옆이나 아래에서 닿으면 피격입니다.
3. **타워 입구 숨은 체크포인트**: 타워 안에서 떨어지면 타워 입구로 돌아옵니다.
4. **Q4 → 최고층 옥상**(지시서 구간 3의 "대시 후 점프 강제"): 간격 360px, 2단 점프만으로는 못 건너고 대시 후 점프로 건넙니다.
5. 월드맵 2번째 맵이라 스테이지 코드는 `2-1`, 카드 id는 `world2_monatium_night`로 바꿨습니다(이전엔 준비 중 카드 `world3_monatium_night`). 정령산 카드는 `world3_spiritmountain`으로 밀었습니다. 둘 다 저장 기록이 없던 카드입니다.
6. 월드맵은 스토리 완주 없이 처음부터 열립니다(사용자 요청). 월드1 안의 스테이지 순서 잠금(1-1 → 1-5)은 그대로입니다.
