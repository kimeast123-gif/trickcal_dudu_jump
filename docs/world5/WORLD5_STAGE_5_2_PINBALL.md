# 월드5 5-2 「루드의 헬스짐」 500kg 핀볼

기획 원본: `DUDU_WORLD5_STAGE52_RUDE_PINBALL_MOTION_REV2_261125.zip`. 코드: `dragon-cave-pinball.js`. 수치: `WORLD5_STAGE_5_2_PINBALL_TUNING.json`.

## 흐름

1. **헬스짐(배경 `02_RUDE_CAVE_GYM_BG`):** 손그림대로 왼쪽 발판(첫 깃발, 루드)과 작은 틈 뒤 둘째 발판(파란 입장 문).
2. **루드 대화:** 두두가 루드에게 120px 안으로 다가가면 대화가 시작된다. 루드는 그때까지 `Idle_1`, 대화 중 `Happy_3`다.
   - 대사 두 줄은 사용자 문구 그대로다. 점프 키를 새로 누르면 다음 줄로 넘어간다(줄이 뜬 뒤 0.35초부터).
   - 끝나면 루드는 `Idle_1`로 돌아가고 파란 입장 문이 밝아진다. 그 전에는 문에 서도 "루드와 먼저 이야기해요"만 뜬다.
3. **입장:** 문 앞에 서면 짧게 어두워졌다가 핀볼판(배경 `03_PINBALL_GYM_BG`)이 화면 전체에 뜬다. 곡이 11번으로 바뀐다.
4. **발사대(손그림 핀볼판 왼쪽 아래 깃발 = 두 번째 체크포인트):** 두두가 동그랗게 만 이단점프 회전 모습(`spin` 시트 3~13번 프레임)으로 스프링 위에 선다.
   - 점프 키를 누르고 있는 동안 충전되고(최대 1.2초, 옆 막대로 표시), 떼면 발사한다.
   - 입장할 때 이미 점프 키를 누르고 있었다면, 한 번 떼고 새로 눌러야 충전된다.
   - 약하게 쏘면 레인으로 도로 떨어져 발사대로 돌아온다. 이때 잃는 것은 없다.
5. **플레이:** 왼쪽·오른쪽 이동 키가 각각 왼쪽·오른쪽 핀이다(동시 입력 가능). 휴대폰은 스틱 좌우가 핀, 점프 버튼이 발사다.
6. **득점:** 20kg 원판 1개, 10kg 3개, 3kg 2개, 샌드백 2개. 닿는 순간 한 번만 점수가 오르고, 떨어졌다가 다시 맞으면 다시 오른다(같은 표적 0.15초 쿨다운).
7. **드레인:** 핀 사이로 빠지면 발사대로 돌아간다. 점수는 그대로고 체력은 줄지 않는다. 공 개수나 시간 제한은 없다.
8. **500kg:** 그 물리 단계에서 바로 성공이 확정되고, 그 뒤로는 득점·드레인·입력을 받지 않는다. "500kg 달성!"이 1.4초 뜬다.
9. **복귀:** 어두워졌다가 두두가 처음 루드를 만난 자리(x 360)에 서서 루드를 본다. 곡은 10번으로 돌아간다.
10. **인정 대사:** 루드가 `Happy_5`로 사용자 문구 한 줄을 말한다. 그 줄을 넘겨야만 5-2 클리어, 5-3 해금, 결과 창이 나온다. 월드5 완료는 저장하지 않는다.

- 틈에 떨어져 다시 시작하면 대화를 마친 상태와 모은 kg를 유지한다. 스테이지를 새로 시작하면 처음부터다.
- 파란 점수창은 그리기만 한다(충돌 목록에 없음). 공이 지나가도 궤도가 바뀌지 않는다.

## 그림 (v1.10.2, 사용자 핀볼 에셋 보드)

`docs/world5/source/pinball_parts_board.webp`를 `tools/dragon_cave_pinball_parts.py`가 부품 19개로 잘라 `assets/world/dragoncave/pinball/`에 둔다. 점수판의 "0kg"과 배지의 "+5kg" 예시 숫자는 지우고 게임이 실제 kg를 쓴다.

- 핀: 핀 그림을 축 중심으로 돌린다. 그림이 축 쪽은 두껍고 끝은 가늘어서, 충돌도 축 반지름 24에서 끝 10으로 가늘어진다. 쉬고 있을 때 두 끝 사이 빈틈은 공 지름의 1.26배다.
- 원판 20/10/3kg: 원판 그림(받침 포함 거의 동그람)을 표적 원에 맞춰 그린다. 맞으면 잠깐 밝아지고 "+kg" 배지가 떠오른다.
- 샌드백: 샌드백 그림을 손그림의 기울어진 막대 방향으로 눕혀 고리를 위쪽 끝에 둔다(충돌 길이 62, 두께 34).
- 점수판: TOTAL 판 그림 안에 현재 kg, 아래에 목표 500kg. 충돌하지 않는다.
- 발사대: 스프링 상자 그림이 충전만큼 눌린다. 위에 초록 깃발, 레인 밖에 신호등(발사 대기 초록, 공이 판에 있으면 빨강), 레인에 위로 향한 노란 화살표.
- 레인 벽: 세로 레일 그림을 이어 붙인다. 핀으로 이어지는 가이드는 짧은 레일 그림이다.
- 바깥 테두리: 보드 모서리 반지름이 손그림과 맞는 조각이 없어서, 레일 색(회색 금속, 빨간 줄)으로 그린다. 공은 테두리 안쪽 선에서 튄다.
- 헬스짐 발판: 보드의 돌 바닥 조각(양 끝은 그대로, 가운데는 반복).

## 효과음 (v1.10.5, `DUDU_RUDE_PINBALL_CONTACT_SFX_FIX_REV1_261125`가 앞 패키지의 연결을 바로잡음)

파일: `assets/sfx/dragoncave/rude_flipper_*.wav` 5개(WAV 사용: 아이폰 사파리가 OGG를 못 읽을 수 있음, 소리는 패키지의 OGG와 같다).

| 상황 | 소리 |
| --- | --- |
| 핀을 새로 누름(누르고 있거나 키 자동 반복은 제외, 양쪽 동시도 한 번) | `swing_miss`만, 작게(0.45) |
| 공이 실제로 핀에 닿음 | `hit_01~03` 중 하나(직전과 다른 것), 크게(1.4) |
| 세게 닿음(닿는 속도 520 이상) | `hit_strong`만(1.3). 기본 타격음과 겹치지 않는다 |
| 공이 벽, 원판, 샌드백에 닿음 | 이번 수정 범위 밖, 기존 소리 그대로 |

- 연결 위치: `pbStep`의 공과 핀 충돌 판정(`pbCollide`가 실제로 밀어낸 순간). 핀마다 따로 센다.
- 한 번의 닿음 = 소리 한 번이다. 공이 핀에 새로 닿을 때, 또는 이미 닿아 있는 공을 위로 휘두르는 핀이 쳐 낼 때 소리가 난다. 같은 핀은 0.065초 쿨다운이 있다. 닿는 속도가 40보다 느리면(공이 핀 위에 그냥 머무는 경우) 소리가 나지 않는다.
- 닿는 속도는 튕기기 직전, 공과 핀 표면이 접점 법선 방향으로 가까워지는 속도다(돌고 있는 핀의 표면 속도 포함).
- 타격음에는 짧은 낮은 '쿵'을 겹친다(v1.10.4, 사용자: 찰지게). 컴프레서를 거쳐 잘리지 않게 한다. 핀볼 곡은 0.5배다(35. Trick Or Treat가 다른 곡보다 약 1.7배 큼). 게임 전체 소리 크기와 음소거를 따른다.
- 확인(헤드리스 브라우저, 이벤트 기록 `window.__pbLog`의 `flipper_press`, `ball_flipper_contact`):
  - 공 없이 핀 10번 → `swing_miss` 10, `hit` 0
  - 왼쪽 핀에 공 10번 떨어뜨림 → `hit` 10, 오른쪽 10번 → 10
  - 핀 위 공을 휘둘러 침 → `swing_miss` 1, `hit_strong` 1(닿는 속도 1,296), 기본 `hit` 없음
  - 올린 핀 안쪽에 공을 1.2초 얹어 둠 → 떨어질 때 `hit` 1번(속도 77) 뒤 조용함
  - 실제로 귀에 들리는 크기는 직접 플레이로 확인해야 한다.

## 표적 효과음 (v1.10.6, `DUDU_RUDE_PINBALL_TARGET_SCORE_SFX_REV1_261125`)

파일: `assets/sfx/dragoncave/rude_target_*.ogg`와 `.wav` 11종씩. 브라우저가 OGG를 재생할 수 있으면 OGG, 아니면(아이폰 사파리) WAV를 쓴다.

| 표적 | 소리 |
| --- | --- |
| 3kg 원판 2개 | `3kg_hit_01/02` |
| 10kg 원판 3개 | `10kg_hit_01/02` |
| 20kg 원판 1개 | `20kg_hit_01/02` |
| 샌드백 2개 | `sandbag_hit_01/02`(점수는 지금 정책 그대로, 임시 5kg) |
| 500kg 달성 | `500kg_clear` 한 번 |

- **30kg 소리:** 패키지에 들어 있고, 표적이 주는 kg로 소리를 고르게 해 뒀다. 그래서 30kg 표적이 생기면 바로 쓰인다. 지금 게임의 맨 위 원판은 사용자 설계대로 20kg이라 20kg 소리가 난다. 패키지 지시대로 원판을 30kg으로 바꾸지 않았다.
- **연결 위치:** `pbScore`, 즉 kg가 실제로 오르는 바로 그 자리다. 점수가 한 번 오를 때 소리도 한 번이다.
  - 붙어 있는 동안에는 다시 오르지 않고(기존 중복 방지), 떨어졌다 다시 맞으면 다시 난다.
  - 같은 묶음 안에서 직전과 같은 소리는 연속으로 나오지 않는다.
- **500kg:** 500kg을 넘기는 타격음은 0.75배로 낮춘다. 0.12초 뒤 클리어음(0.92초)이 한 번 난다. 성공 연출이 1.4초라 루드 앞으로 돌아가기 전에 끝난다. 그 뒤로는 물리가 멈춰서 표적 소리가 더 나지 않는다.
- **크기:** 1.1. 핀 소리와 같은 컴프레서를 거치고, 게임 전체 소리 크기와 음소거를 따른다.
- **확인**(헤드리스 브라우저, `window.__pbLog`의 `hit`, `sfx_clear`):
  - 각 표적에 공을 10번 보냄
    - 20kg, 10kg 3개, 3kg 2개, 오른쪽 샌드백: 득점 10번, 소리 10번
    - 왼쪽 샌드백: 한 번은 공이 되튀어 한 번 더 맞아서 득점 11번, 소리 11번
    - 두 소리가 번갈아 나왔다.
  - 핀만 6번 누름 → 표적 소리 0
  - 495kg에서 10kg 명중 → 타격음 1, 성공, 클리어음 1. 그 뒤 핀을 눌러도 표적 소리 없음
  - 실제로 귀에 들리는 크기는 직접 플레이로 확인해야 한다.

## 핀볼 물리

- 보드 좌표는 손그림의 픽셀 그대로다(보드 x 322~833, y 14~778). 화면에는 레일까지 0.83배로 그려서 보드 전체가 1280×720 안에 들어간다.
- 120Hz 물리 단계마다 4번 나눠 계산한다(1/480초). 최고 속도 1,500에서 한 번에 3.1 단위만 움직여서 공 반지름(17)보다 작다. 그래서 표적을 뚫고 지나가지 않는다.
- 벽은 둥근 바깥 테두리(모서리 반지름 95), 발사 레인 벽, 핀으로 이어지는 양쪽 가이드다. 레인 윗부분에는 한쪽으로만 열리는 문이 있어서, 판으로 나간 공은 레인으로 되돌아오지 않는다.
- 핀은 축을 중심으로 도는 막대(반지름 축 24, 끝 10)다. 돌아가는 속도로 접점 속도를 계산해 공을 쳐낸다.
  - 길이 108은 판 폭의 26%다.
  - 쉬고 있을 때 두 핀 끝 사이 빈틈은 약 43으로, 공 지름의 1.26배다.
  - 처음 그림에서 핀이 짧고 가운데가 넓던 문제는 길이와 각도로 줄였다. 가운데 빈틈은 남겨서 놓치면 빠진다.
- 원판은 부딪히면 튕겨 내는 힘(260)이 더해진다. 샌드백은 140이다.
- 공이 판 위에서 1.5초 넘게 거의 멈춰 있으면 살짝 밀어 준다.

## 정해 주셔야 할 것

- **샌드백 1회 kg:** 임시로 5kg(`SANDBAG_SCORE_KG`)이다. 기획서 제안값이고 확정값이 아니다.
- **루드 모션 크기:** `Happy_5`만 조금 넓게 찍혀 있어서 머리 크기에 맞춰 키웠다(0.88 보정). 바뀌는 순간 크기가 튀어 보이면 알려 주세요.
- **휴대폰 핀 조작:** 지금은 스틱 좌우가 핀이다. 기획서의 큰 좌우 터치 영역은 아직 없다.
- 기획서의 "5-2 체크포인트 2 = 발사대"는 핀볼 안의 깃발로 표시했다. 월드 체크포인트 목록에는 넣지 않았다. 헬스짐에서 떨어지면 첫 깃발로 돌아간다.
