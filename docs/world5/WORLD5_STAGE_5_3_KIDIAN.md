## 맵 (v1.10.9: 손그림 비율 그대로)

손그림(1102×425)을 **가로세로 같은 배율**로 옮겼다: x = 60 + 손그림 x × 3.2, y = 580 + (손그림 y − 252) × 3.2. 손으로 옮긴 곳은 없다. 맵 폭은 3,700px이다.

- **v1.10.9로 고친 이유(사용자 지적):**
  - 전에는 가로 3.5배, 세로 2배로 옮겨서 높이가 눌렸다. 그래서 벽이 2단 점프(약 279px)보다 낮아 넘어갈 수 있었고, 아래 길의 구덩이는 B1 밑으로 건너기에 너무 길었다.
  - v1.10.8에서는 B1 줄 끝에 `//` 주석을 붙이는 실수로 B2, B3, B4 발판이 아예 빠져 있었다(CLAUDE.md의 한 줄 `//` 금지 규칙 위반). 이번에 바로잡았다.
- **발판:** 손그림의 갈색 밑면 발판은 모래 덮인 돌, 검은 발판은 맨 돌이다. 시작과 골은 깃발이 달린 받침 그림이다. 중간 체크포인트는 없다.
- **갈색 벽:**
  - W1(ㄱ 세로 벽, 458px): B1이 이 벽에서 끝난다.
  - W2(ㄱ 들보, 윗면에 흑요석 7개, 사용자 지시)
  - W3(오른쪽 위): 화면 위에서 D1까지 내려온다.
  - W4(오른쪽 아래, G3 위 291px)
  - 모두 2단 점프로 넘을 수 없다.
- **바닥 바위:** 손그림 맨 아래 검은 상자 3개(G1~G3)다. 그 사이는 떨어지는 곳이고, 1250 아래면 다시 시작한다. 떨어지는 곳은 어두운 안개로 덮었다.
- **흑요석:** 빨간 표시 6곳(A4 가운데, C1 양끝, C4 양끝, C6 가운데)과 들보 위 7개. 닿으면 체력 1과 넉백이다.
- **길(손그림 그대로):**
  - 위쪽: S → A1 → A2 → A3 → A4 → A5 → C3 → C6 → C8 → D1. D1은 W3에 막힌 끝이라 C9나 C10으로 내려간다.
  - 아래쪽: S → B1 → (B1 왼쪽 끝에서) G1 → B1 밑으로 낮게 뛰어 G2 → ㄱ 세로 벽 아래를 걸어서 → B4 → B3 → B2 → C2 → C5 → C7 → C10 → D2 → 골.
  - A1에서 A4는 339px 높아 직행할 수 없다(손으로 올리지 않아도 됨).
- **점프 요구(계산):**
  - 2단 점프가 필요한 곳: S→A1 221, A1→A2 198, B3→B2 167, C7→C10 224, C2→C1 262(가장 높음), D2→골 같은 높이 330.
  - 한 번 점프로 가는 곳: A3→A4 176, B4→B3 153 등.
- **추락선:** 월드 스테이지 기본 추락선이 850으로 고정돼 있어서, 바닥이 더 낮은 5-3은 `killYAt`로 1250을 쓴다.

## 시야

- 가비아 마스크를 그대로 쓴다. 평소 반경은 250이고, 가비아는 210이다.
- 시작 뒤 15초, 30초, 45초…부터 3초 동안 반경 150으로 좁아진다. 줄어들고 넓어지는 0.3초씩은 그 3초 안에 들어 있어서 3초를 넘기지 않는다.
  - 확인값: 14.9초 250, 15.0초 250, 15.15초 200, 15.3~17.7초 150, 17.85초 200, 18.0초 250, 30.2초 176, 33.0초 250, 45.5초 150
- 시계는 5-3 자체 시계라 게임이 멈추면(일시정지, 메뉴) 같이 멈춘다. 떨어지거나 다시 시작하면 0부터 다시 센다.
- 안내 글이나 타이머 표시는 없다.

## 키디언

- **모션:** `tools/dragon_cave_motions.py`가 GIF를 시트로 만든다.
  - 크기(v1.10.9, 사용자 지적: 멈춤, 춤, 이동, 착지, 날기에서 크기가 달라 보임. 날기가 특히 컸음): 모든 동작을 서 있기(Idle_2) 옆에 한 줄로 그려 놓고, 머리 크기와 키가 같아 보이게 배율을 다시 맞췄다.
    - 그림 자체가 달릴 때는 머리를 작게, 춤출 때는 머리카락을 넓게 그려서, 머리나 키 한쪽만 보고는 맞지 않았다.
    - 배율(게임 px / GIF px): 서 있기 0.113, 이동 0.120, 춤 0.107, 착지 0.270, 날기 0.160(전 0.25).
    - 키: 서 있기 115, 이동 114, 춤 107~109, 착지 105px. 날기는 엎드린 자세라 높이 74px.
  - **날기(v1.10.9, 사용자):** 뛰어올라 다음에 내려설 때까지는 날기 GIF(`docs/world5/source/Kidian_Fly.gif`, 3프레임, 수평으로 날아가는 자세)를 반복한다.
    - 공중제비(skill 4의 2~5번)는 계속 빙글빙글 도는 게 어색하다고 하셔서 뺐다.
    - 몸 가운데에 고정해 키디언이 따라가는 길로 날아간다.
  - **착지:** 내려서면 skill 4의 6~9번(웅크림)을 한 번 재생한다. 0~1번은 검은 실루엣이라 쓰지 않는다.
- **따라오기:** 두두가 지나간 길을 110px 뒤에서 그대로 따라온다(점프 궤적 포함, 벽을 뚫거나 떨어지지 않음).
  - 길의 각 점에 두두가 땅에 있었는지 기록한다. 두두가 뛰었다가 바로 멈추면 키디언이 공중에 떠 있지 않고, 두두가 내려선 자리까지 와서 선다.
  - 움직이면 Move, 0.15초 서 있으면 Idle_2다.
- **「교주님」:** 두두가 서서 `CallPlayer` 음성(교주님 부르기)을 내면, 키디언이 서 있을 때 Dance_1이나 Dance_2를 한 번 춘다. 게임에 있던 `onDuduCallPlayerVoice` 사건을 쓴다.
