## 5-1 제이드의 금고

배치표: `JADE_MAP1_PLATFORM_COORDS.csv`, 우회 검사: `JADE_MAP1_UNINTENDED_REACH.csv`.

- 맵 폭 9,700px. 손그림의 발판 수(시작 1, 1구간 14, CP2 1, 2구간 13, 골 1)를 그대로 두고 발판 사이를 한 번 점프 거리(간격 135~200px, 오르기 70~110px)로 맞춘 결과다. 기획 권장(9,600~10,400px) 안에 든다.
- 아래 갈색 바닥은 땅이 아니다. 깊은 안개 낀 낭떠러지로 그리고, 닿으면 체크포인트에서 다시 시작한다(바닥선 + 30px).
- 제이드와 오팔은 그 바닥선 위를 걷는다(손그림 왼쪽 아래 빨간 원 두 개 자리에서 시작).

### 흐름 (REV3, `DUDU_WORLD5_STAGE51_JADE_OPAL_MOTION_REV3_261125`)

모션: `tools/dragon_cave_motions.py`가 `03_NPC_MOTIONS`의 GIF 7개를 `assets/npc/dragoncave/`(시트 + `atlas.js`)로 만든다. **Move 모션은 패키지에 있다**(`Jade_Move.gif`, `Opal_Move.gif`, 문서에는 없다고 적혀 있었음). 그래서 `MOVE_ASSETS_MISSING` 상태가 아니다.

| 동작 | 쓰는 곳 |
| --- | --- |
| `Jade_Move` | 제이드가 걸을 때 |
| `Jade_Angry_2` | 제이드가 서 있을 때(항상 화난 얼굴) |
| `Opal_Move` | 오팔이 달릴 때(책 단계의 이동, 오열 자리로 가는 길) |
| `Opal_Happy_7`, `Opal_Happy_8` | 책 단계에서 멈출 때마다 둘 중 하나를 무작위로, 그 동작 중 한 번 책을 던짐 |
| `Opal_Sad_6`, `Opal_Sad_10` | 오열 자리에서 울 때 둘 중 하나를 무작위로, 그 동작 중 한 번 눈물을 던짐 |

- 크기: 제이드는 Move와 Angry의 확대 비율이 같다. 오팔 Move는 다른 동작과 거의 같다(0.96). 일곱 동작을 게임 안에 나란히 그려 맞췄다. 둘 다 약 120px(마요 129px).
- GIF의 Move에만 있던 검은 바닥 그림자는 지우고, 모든 동작 아래에 같은 옅은 그림자를 그린다.
- 던지는 순간: 동작에 따로 던지는 자세가 없어 프레임을 하나씩 보고 몸이 가장 높이 튀는 순간으로 정했다. Happy_7 500ms(15번째 프레임, 손을 올림), Happy_8 330ms(10번째), Sad_6 270ms(8번째), Sad_10 130ms(4번째).

1. **책 단계(시작 → CP2):** 오팔이 Move로 250~500px 달린다. 멈추면 Happy_7이나 Happy_8을 한 번 하면서 책을 한 묶음 던진다(v1.10.1, 2배로: 구간 A 4권, B 6권, C 6권, D 8권). 끝나면 다시 달린다. 달리는 중에는 던지지 않는다.
   - 두두가 700px보다 멀어지면 오팔은 멈추지 않고 두두 150px 뒤까지 빠르게(560px/s) 따라온다(이때도 던지지 않음). 한 번에 250~500px만 달리면 두두보다 느려 한참 뒤처졌기 때문이다.
   - 두두가 시작 발판 위에 있는 동안에는 던지지 않고 제자리에서 Happy만 한다.
   - 제이드는 두두 170px 뒤를 따라간다(걸을 때 Move, 서면 Angry). 책은 던지지 않는다.
2. **CP2 도착:** 구간 D를 지나 CP2에 내려서면 두두가 0.8초 멈추고 날아오던 책이 사라진다. 새 책 공격은 없다. 두 캐릭터는 CP2 아래(오팔 x 5,130, 제이드 x 5,020)에서 기다린다.
3. **파란 점선(x 5,240, CP2 깃발 오른쪽):** CP2 뒤에 두두가 이 선을 넘으면 한 번만 발동한다. 오팔과 제이드가 Move로 오열 자리까지 멈추지 않고 달린다(520px/s). 가는 동안 책도 눈물도 없다.
4. **눈물 단계:** 오열 자리에 닿은 뒤에만 오팔이 Sad_6이나 Sad_10으로 울며 눈물을 던진다(v1.10.1, 2배로: T1 2.1초 6방울, T2 1.8초 8방울, T3 1.55초 10방울). 같은 때 눈물이 화면 위에서 두두 주변 좌우 420px 안 아무 곳에나 곧장 쏟아진다(T1 4, T2 5, T3 6방울). 그 자리 아래 발판(두두 발판이든 더 아래 발판이든)에 떨어지고, 발판이 없으면 안개 속으로 지나간다. 제이드는 왼쪽 120px에서 Angry로 서 있다.
   - 오열 자리는 구간마다 하나씩이다: T1 x 6,300, T2 x 7,450, T3 x 8,550. 두두가 다음 구간에 들어가면 오팔이 Move로 다음 자리로 달리고(가는 동안 눈물 없음), 닿으면 다시 운다. 기획서는 오열 자리를 하나로 적었지만, 한 자리에서는 골 근처까지 눈물이 2,500px 넘게 날아가야 해서 나눴다. 하나로 바꾸려면 알려 주세요.
5. **큰 울음(T2, T3):** 오팔이 우는 동안 6.5초(T2), 5.5초(T3)마다 "오팔이 울먹여요!" 예고가 0.9초 뜬 뒤 두두가 0.38초 동안 움직이지 못한다. 발판 위에서 가장자리와 떨어져 서 있을 때만 걸리고, 1.2초 안에 그런 순간이 없으면 그 울음은 넘어간다. 멈춘 동안과 풀린 뒤 0.3초는 눈물에 맞지 않는다.
6. **골:** 5-1 통과 창이 뜨고 5-2가 열린다.

- **얼굴 말풍선(v1.10.3, 사용자 지시):** 제이드나 오팔의 얼굴이 화면 밖(주로 아래)에 있으면, 그 x 위치의 화면 아래 끝에 꼬리가 아래를 향한 말풍선이 뜬다. 안에는 지금 동작의 프레임을 얼굴 중심으로 확대해 넣어서, 표정과 동작이 그대로 움직인다. 둘이 겹치면 좌우로 벌린다.

### 확인한 것 (스크린샷과 상태 값, 직접 완주는 하지 않음)

- 시작, 책 구간 A·D, CP2 도착, 파란 점선 통과 뒤 이동, T1과 T2의 오열, CP2 다시 시작 화면을 1280×720에서 찍었다.
- 이벤트 기록은 `JADE_STAGE51_NPC_TIMELINE.csv`에 있다(`window.__dcLog`). 순서: `opal_move` → `opal_stop_happy`(Happy_7/8) → `book_volley` 반복 → `cp2_reached` → `cp2_hold_end` → `blue_line_crossed` → `crying_spot_reached` → `opal_cry_start`(Sad_6/10) → `tear_volley`.
  - 순간이동처럼 보이는 좌표는 확인용으로 두두를 옮긴 것이다. 게임 안 캐릭터는 매 프레임 이어서 움직인다.
- 파란 점선 전에는 눈물이 없고, 오열 자리에 닿기 전에는 눈물 발사 기록이 없다.
