# 두두의 폴짝폴짝 대모험

**v0.3.2-beta · TEST28.6 회귀 결함 통합 수정본 (1.0 후보 이전 검수용)**

[게임 플레이하기](https://kimeast123-gif.github.io/trickcal_dudu_jump/)

두두가 수인숲, 수인마을, 모나티엄 A·B, 에르피엔 A·B를 지나 엄마를 만나러 가는 2D 횡스크롤 팬게임입니다. 스토리 모드와 별개로 **〈추억의 인내의 숲〉** 3단계 챌린지가 있습니다.

## 조작

| 키 | 기능 |
|---|---|
| ← → | 이동 |
| SPACE | 점프 / 2단 점프 |
| L SHIFT | 대시 |
| ↓ + SPACE | 얇은 발판 내려가기 |
| ↓ 길게 | 아래보기 |
| R | 체크포인트부터 재도전 |
| ESC | 일시정지 |

## 배포

GitHub Pages 설정: `Settings → Pages → Deploy from a branch → main / (root)`.

**배포 필수:** ZIP 내부의 `assets/` 디렉터리 전체를 함께 배포해야 합니다. 특히 `assets/terrain/erpien/stone_inner_strip.webp`와 `gate_inner_strip.webp`가 빠지면 로딩 실패가 발생할 수 있습니다. 폰트는 기기 설치 폰트 또는 시스템 한글 폰트로 대체됩니다.

## 통계

`release-config.js`의 `analyticsEnabled` 기본값은 `false`입니다. 외부 분석 서비스로 플레이 데이터를 보내지 않습니다. 통계를 사용하려면 먼저 개인정보 안내·동의 UI를 마련하고 공개 프로젝트 토큰을 설정해야 합니다. 개발 서버에서 검증하지 않은 상태에서 임의로 켜지 마세요.
