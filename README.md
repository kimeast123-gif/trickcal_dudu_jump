# 두두의 폴짝폴짝 대모험 (TEST34 · 261116 UI/UX 디자인 개편판)

에피드게임즈 〈트릭컬 리바이브〉 세계관과 캐릭터를 바탕으로 제작한 비공식 팬게임입니다.

## 261116 UI/UX 총괄 개편 요약
1. **P0 — 이동·점멸 플랫폼 보조 표식 제거 (`renderer.js`)**
   - 상하/좌우 이동 플랫폼의 방향 배지·화살표·추가 상단 강조 림을 제거했습니다.
   - 점멸 플랫폼의 잔여시간 진행 바·수축 경고 바·복귀 진행 게이지·코너 브래킷·타이머용 점선 슬롯을 제거했습니다.
   - 얇은 발판의 통과 가능 노치(`▾`)와 하강 금지 잠금 브래킷(`dropThroughDisabled`) 및 기존 월드 이동 레일 연출, `game.js`의 실제 이동·점멸·충돌 로직은 그대로 유지합니다.
2. **P1/P2 — 단일 디자인 시스템 통합 ('트릭컬풍 숲속 모험의 조용한 인터페이스')**
   - 웜 크림 표면(`#FAF6EE`), 짙은 숲색 잉크(`#29372E`), 회녹색 보조 잉크(`#68756A`), 주 행동색(`#5F965B`), 절제된 성취 금색(`#CDA45B`) 토큰으로 전 화면 모달·카드·버튼을 통일했습니다.
   - 로비 5개 메뉴를 3단계 위계(1순위 `플레이` / 2순위 `월드맵·챌린지 모드` / 3순위 `키 설명·게임옵션`)로 정리하고 과장된 다중 테두리·광택·발광 효과를 덜어냈습니다.
   - 인게임 HUD를 32px 높이의 소형 캡슐과 고정폭 숫자(`tabular-nums`)로 정돈해 캐릭터 시야와 착지 지점 가림을 최소화했습니다.
