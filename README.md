# 두두의 폴짝폴짝 대모험 (Dudu's Little Adventure)

**v1.0 정식 릴리즈 버전** — 스토리 모드(6개 지역) · 월드1 「수인숲 나들이」(1-1 ~ 1-5) · 챌린지 모드 「추억의 인내의 숲」

## v1.0 주요 기능
- **스토리 모드 (6개 씬 · 25분 귀갓길)**:
  - 수인숲 → 수인마을 → 모나티엄 A → 모나티엄 B → 에르피엔 A → 에르피엔 B(엄마의 방)
  - 공식 황금 크레파스 12개 올 컬렉션 시 특별 엔딩 분기 제공
- **월드1 「수인숲 나들이」 (1-1 ~ 1-5)**:
  - 스토리 모드 1회 완주 시 해금되는 7카드 월드맵 탐험 시스템
  - 월드1 전용 황금 크레파스 5개 및 수인마을 친구들(디아나·코미·버터·란·벨리타·리뉴아·우로스·슈로·티그) 상호작용
- **챌린지 모드 「추억의 인내의 숲」**:
  - 난이도 1 (Stage 1 `가지와 가지 사이` · Stage 2 `진압반의 징검다리` · Stage 3 `마요의 바람총 숲`)
  - 난이도 2 (`2-1 · 정밀 3층 등반` 신규 수록, `2-2`·`2-3` 추후 업데이트 예정)
- **360° 모바일 가상 조이스틱 & 독립 점프/대시 버튼 크기 조절**

## 실행 방법
정적 웹 서버 또는 GitHub Pages에 루트 파일(`index.html`, `style.css`, `title-lobby.css`, `*.js`, `assets/`)을 배포하여 바로 실행할 수 있습니다.
