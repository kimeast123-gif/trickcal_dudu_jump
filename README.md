# 두두의 폴짝폴짝 대모험 v1.1

에피드게임즈 〈트릭컬 리바이브〉의 캐릭터로 만든 비공식 팬게임입니다.
해가 지기 전에 숲과 마을, 도시를 지나 엄마가 기다리는 집으로 돌아가는 2D 플랫포머입니다.

## 실행
정적 웹 페이지입니다. 저장소 최상단을 GitHub Pages 같은 정적 호스팅에 올리면 됩니다.
로컬에서는 `python -m http.server` 같은 간단한 서버로 `index.html`을 열어 주세요(파일을 더블클릭해 열면 이미지와 폰트가 막힙니다).

## 조작
| 동작 | PC 기본 키 | 모바일 |
| --- | --- | --- |
| 이동 | ← → (A D) | 스틱 |
| 점프, 2단 점프 | SPACE (↑, W) | 점프 버튼 |
| 대시 | L SHIFT, 또는 방향 두 번 누르기 | 대시 버튼, 또는 스틱 두 번 밀기 |
| 아래보기 | ↓ 꾹 누르기 | 스틱 ↓ |
| 떠 있는 발판에서 내려가기 | ↓ + SPACE | 스틱 ↓ + 점프 |
| 구간 다시 시작 / 일시정지 | R / ESC | 화면 버튼 |

모든 키는 게임 옵션에서 바꿀 수 있습니다. 이미 쓰고 있는 키를 고르면 두 동작의 키가 서로 바뀝니다.

## 발판 규칙
- 땅(두께가 있는 지면)은 단단합니다.
- 떠 있는 발판은 모두 아래에서 뚫고 올라갈 수 있습니다. 발판 위에서 ↓를 누르면 내려갈 수 있는지 바로 표시됩니다(아래 화살표는 가능, 자물쇠는 불가).
- 사라지는 발판은 사라진 동안 윤곽이 남고, 점점 짙어지다가 돌아오기 직전에 깜빡입니다.

## 설정
`release-config.js`의 `releaseMode`와 `qaBuild`로 배포와 QA 빌드를 전환합니다. QA 빌드에서만 개발용 연습 막대가 보입니다.
통계(`analyticsEnabled`)는 동의 화면이 준비되기 전까지 꺼 두었습니다.

## 폰트
`assets/fonts/ONE-Mobile-POP.ttf`를 사용합니다. 공개 배포 전에 폰트의 재배포 조건을 확인해 주세요.
