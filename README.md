# 두두의 폴짝폴짝 대모험

**v0.2.0-beta · TEST21 개발본 기반 배포 패키지**

[게임 플레이하기](https://kimeast123-gif.github.io/trickcal_dudu_jump/)

두두가 수인숲, 수인마을, 모나티엄, 에르피엔을 지나 엄마를 만나러 가는 2D 횡스크롤 팬게임입니다. 스토리 모드와 별개로 **〈추억의 인내의 숲〉** 3단계 챌린지가 있습니다.

## 조작

| 키 | 기능 |
|---|---|
| ← → | 이동 |
| SPACE | 점프 / 2단 점프 |
| L SHIFT | 대시 |
| ↓ + SPACE | 얇은 발판 내려가기 |
| ↓ 길게 | 아래보기 |
| R | 체크포인트부터 재도전 |
| ESC | 일시정지 |

## 배포

GitHub Pages 설정: `Settings → Pages → Deploy from a branch → main / (root)`.

**중요:** 이 전달 ZIP은 폰트 바이너리를 포함하지 않습니다. 사용자에게 이미 있는 `ONE Mobile POP.zip`을 사용해 `assets/fonts/one-mobile-pop.otf` 파일을 설치한 뒤 올려야 합니다. 자세한 단계는 `00_배포준비_안내.md` 참고.

## 통계

`release-config.js`의 `analyticsEnabled` 기본값은 `false`입니다. 외부 분석 서비스로 플레이 데이터를 보내지 않습니다. 통계를 사용하려면 먼저 개인정보 안내·동의 UI를 마련하고 공개 프로젝트 토큰을 설정해야 합니다. 개발 서버에서 검증하지 않은 상태에서 임의로 켜지 마세요.

## 업데이트

- TEST21 스토리 4지역 및 챌린지 3단계 포함
- 수인마을 우호 NPC(디아나·코미·버터), 에르피엔 마요·마리 보스전 반영
- 개발 전용 UI 숨김 및 릴리스용 문구 정리
- ONE Mobile POP 폰트 사용 경로 및 초기 로딩 구성 유지

## 라이선스

비공식 팬게임이며 원작 및 에셋 권리는 각 권리자에게 있습니다. 폰트 포함 재배포 전에는 해당 글꼴의 라이선스와 사용 조건을 별도로 확인하세요.
