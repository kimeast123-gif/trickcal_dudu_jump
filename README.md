# 두두의 폴짝폴짝 대모험 (1.0 출시 후보 패치 · RC1 보완판)

에피드게임즈 〈트릭컬 리바이브〉 세계관과 캐릭터를 바탕으로 제작한 비공식 팬게임입니다.

## RC1 패치 반영 범위 (TEST34 기준 변경점)

1. **작업 묶음 A — 입력 · 카메라(`아래보기`) · 발판 통과 · PC 조작키 설정**
   - **아래보기(`↓` 홀드) 복구 및 경계 준수**: `general` 카메라 프로필(수인숲·수인마을) 및 `world1`·`challenge` 카메라에서 `window.camBaseY`와 `lookDownOffset`을 분리해 `↓` 홀드 시 하단 시야를 확보하되, 각 스테이지에 정의된 `[minCamY, maxCamY]` 경계를 초과하지 않도록 클램핑했습니다.
   - **아래보기와 발판 통과 분리**: `↓` 단독 홀드는 카메라 아래보기 전용이며, 통과 가능한 얇은 발판(`thin: true, !dropThroughDisabled`) 위에서 `↓ + 점프` 입력 시에만 아래로 내려갑니다 (`dropThroughDisabled: true` 및 두꺼운 지면은 하강 차단).
   - **PC 사용자 지정 조작키(`게임 옵션 → ⌨️ PC 키보드 조작 설정`)**:
     - PC 접속 시 옵션 창 상단(전체 사운드 바로 아래)에 배치되어 스크롤 없이 좌/우 이동, 아래보기, 점프, 대시, 구간 다시 시작, 일시정지 7개 행동을 변경·저장(`dudu_keyboard_bindings_v1`)할 수 있습니다.
     - `Escape` 키는 일시정지 외 다른 행동에 배정할 수 없도록 API·저장 로더 양측에서 차단하며, `PAUSE`를 다른 키로 변경하더라도 `Escape` 예비 일시정지 동작이 항상 보장됩니다.
     - 텍스트 입력 요소(`input`, `textarea`, `contenteditable`) 포커스 시에는 게임 단축키 라우팅과 `preventDefault()`를 중단해 문자 입력을 가로채지 않습니다.
     - 로비 `키 설명` 모달에서 `[⚙️ 키 설정 열기]`로 진입한 뒤 옵션 창을 닫으면 원래 `키 설명` 모달과 버튼 포커스로 복귀합니다.

2. **작업 묶음 B — 발판 유형별 시각 보조 표식 및 점멸 복귀 게이지**
   - **금번 패치 신규 추가 범위**:
     - **통과 가능 얇은 발판(`thin: true, !dropThroughDisabled`)**: 발판 하단 중앙에 아래쪽 화살표 노치(`▾`)를 표시합니다 (`w >= 72px` 일반 규격 / `38~71px` 좁은 발판은 착지면을 침범하지 않는 소형 노치 적용).
     - **하강 불가 얇은 발판(`dropThroughDisabled: true`)**: 발판 하단에 어두운 잠금 브래킷 바를 표시합니다.
     - **이동형 발판(`motion`, 본편·챌린지)**: 상단 이동 림 및 중앙 방향 배지(`w >= 72px` 일반 배지 / `38~71px` 소형 화살표 배지)를 표시하며, 월드 1(`isWorldMode`)에서는 기존 손그림 이동 레일 디자인을 보존하기 위해 추가 배지를 중복 표시하지 않습니다.
     - **점멸 발판(`behavior === 'blink'`)**: `game.js:platformStep()`의 단일 상태값(`blinkRemaining`, `blinkStateProgress`, `blinkImminent`)을 참조하여 ON(코너 브래킷+상단 바), WARNING(점선 경고 테두리+수축 바), OFF(점선 외곽선+`0%→100%` 복귀 진행 게이지+복귀 `0.28초` 전 예고 강조)를 표시합니다.
   - **기준 빌드(TEST34) 기존 구현 유지 범위**:
     - 두꺼운 지면(`groundTile`) 타일링, 챌린지 비충돌 마요 받침대(`nonCollidable: true`) 및 가시(`challengeSpikes`) 렌더링, 월드 1 손그림 이동 레일은 기존 TEST34 렌더러를 그대로 유지합니다.

3. **작업 묶음 D · E — 문구 정리 및 릴리즈 설정**
   - 로비 `키 설명` 및 페이지 하단에 비공식 팬게임 및 원작(`에피드게임즈 〈트릭컬 리바이브〉`) 표기를 명시했습니다.
   - `release-config.js` (`releaseMode: true`, `qaBuild: false`) 기준 개발용 연습 네비게이션(`.practiceNav`, `.encounterNav`, `F3` 디버그 HUD)을 숨김 처리했습니다.
