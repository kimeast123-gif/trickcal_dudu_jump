# 두두의 폴짝폴짝 대모험

**TEST31.4-beta · 월드맵 / 수인숲 나들이 배포본** (정식 1.0 이전)

[게임 플레이하기](https://kimeast123-gif.github.io/trickcal_dudu_jump/)

두두의 횡스크롤 팬게임입니다. 기존 스토리 모드 6개 맵과 별도의 챌린지 모드를 유지하고, 스토리 정상 완주 시 월드맵이 해금됩니다.

## TEST31.4 주요 기능

- 월드맵: 스토리 모드 재도전, 수인숲 나들이(1-1~1-5), 추후 예정 지역 카드
- 수인숲 5개 스테이지: 점멸/상하 이동 플랫폼, 가시 촉수, 분기 루트, 귀환 마을
- 수인마을 1-5: 디아나, 루포, 티그(영웅), 베니, 모모, 버터, 코미, 바나, 란 NPC 상호작용
- 신규 NPC 6명의 Idle/Happy 애니메이션, 란 대사
- 월드1 황금 크레파스 각 스테이지 1개(총 5개), 스토리 수집물과 별도 기록
- 네온사우르스 5칸 체력, 모바일 조이스틱 및 점프·대시 크기 조절, 음량 설정

## 조작

- `←` `→` 이동 / `SPACE` 점프·2단 점프 / `L SHIFT` 공중 대시
- `↓ + SPACE` 얇은 발판 내려가기 / `↓` 길게 아래 보기 / `R` 재시작 / `ESC` 일시정지
- 모바일에서는 가로 플레이를 권장합니다. 설정에서 모바일 조작 버튼 크기·위치를 변경할 수 있습니다.

## GitHub Pages 배포

`Settings → Pages → Deploy from a branch → main / (root)`.

모든 `.js`, `.css`, `index.html`과 참조되는 `assets/` 경로를 유지해야 합니다. 웹 UI에 업로드할 때는 ZIP 자체가 아니라 **압축을 푼 파일/폴더를 저장소 최상위로** 업로드합니다.

이 게임은 비공식 팬게임입니다. 작품 및 에셋의 권리는 원저작권자에게 있습니다.
