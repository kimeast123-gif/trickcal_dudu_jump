# 두두의 폴짝폴짝 대모험

> 엄마를 만나러 가는 두두의 15분짜리 작은 모험.

**현재 공개 버전:** `v0.1.0-beta` (1차 공개 테스트)  
**플레이:** https://kimeast123-gif.github.io/trickcal_dudu_jump/

## 게임 소개

두두와 함께 **수인숲 → 모나티엄 → 에르피엔**을 지나 엄마가 기다리는 방까지 이동하는 2D 횡스크롤 플랫포머 팬게임입니다.

- **15분 타임어택:** 제한 시간 안에 엄마에게 도착하세요.
- **자유로운 이동:** 가변 높이 점프, 2단 점프, 공중 대시를 활용하세요.
- **수집 요소:** 길 위의 **왕사탕**을 모으고, 어려운 곳에 숨겨진 **황금 크레파스 9개**에 도전하세요.
- **여러 엔딩:** 시간 내 귀가·늦은 귀가·특수 수집 조건에 따른 엔딩 분기가 있습니다. 특수 엔딩의 전용 연출은 아직 제작 중입니다.

## 조작법 (PC 키보드)

| 키 | 조작 |
| --- | --- |
| `←` `→` | 좌우 이동 |
| `Space` | 점프 / 공중에서 한 번 더 누르면 2단 점프 |
| `Left Shift` | 대시 (공중에서 1회 사용 가능) |
| `↓` + `Space` | 아래로 통과 가능한 발판 내려가기 |
| `R` | 현재 체크포인트 재도전 |
| `Esc` | 일시정지 |
